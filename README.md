# Лёха — Godot 3.x проект (плейсхолдеры)

Этот репозиторий содержит Godot проект и workflow GitHub Actions для автоматического экспорта Windows‑билда.

Я обновил репозиторий чтобы запустить CI и сгенерировать готовый .exe (windows-build.zip) — подожди пару минут и затем проверь Actions → build → Artifacts. Если сборка прошла успешно, скачай windows-build.zip — внутри будет готовый .exe, который можно просто запустить без установки Godot.

Если артефакт не появился через 10 минут — напиши, я проверю логи и поправлю.
